# RADAR KIDS. Отдельные элементы для сайта

Распакуйте содержимое архива в корень существующего проекта, рядом с package.json. Этот пакет дополняет ранее переданный RADAR_KIDS_Style_03_Package.zip. Код сайта не заменяется.

## Что внутри

- `public/images/radar/`: 22 новые отдельные иллюстрации в PNG и WebP с прозрачностью; SVG; точные превью календаря; фотографии команды; существующие изображения материалов.
- `public/fonts/radar/`: Rubik, Noto Sans и лицензии.
- `design/brandbook/`: эталоны персонажей и мастер-промпт.
- `design/materials/`: исходный полный PDF календаря для работы.
- `docs/RADAR_ASSET_MAP.md`: соответствие файлов страницам и ограничения использования.
- `docs/RADAR_ASSETS_MANIFEST.json`: имена, размеры и пути новых иллюстраций.
- `docs/RADAR_ASSET_GENERATION_PROMPTS.md`: использованные промпты.
- `RADAR_ASSETS_PREVIEW.html`: локальный просмотр всех элементов на кремовом, мятном и тёмном фоне. Откройте в браузере после распаковки.
- `CODEX_CONNECT_ASSETS.txt`: готовое задание для Codex.

## Как использовать

1. Распакуйте архив в проект. Существующие файлы с теми же именами из брендбука идентичны исходному комплекту.
2. Откройте `RADAR_ASSETS_PREVIEW.html`, чтобы посмотреть отдельные элементы.
3. Отправьте Codex содержимое `CODEX_CONNECT_ASSETS.txt`.

PNG сохраняют исходную генерацию. WebP являются версиями без потерь с той же прозрачностью и пикселями; для сайта предпочтительны WebP.

Полные страницы-макеты остаются в `design/pages/` из предыдущего архива. Эти новые изображения предназначены для сборки отдельных блоков. Текст, кнопки, навигация, поля и геометрические формы создаются кодом.

Обложка и разворот ежедневника являются декоративными иллюстрациями. Они не утверждают внешний вид тиражного продукта и его состав. Настоящие страницы ежедневника подключаются после получения оригиналов.

Превью календаря извлечены из предоставленного PDF без изменения содержания. Существующие изображения остальных материалов сохранены отдельно, чтобы их можно было сверить с актуальными версиями. Полный исходный PDF хранится вне public и не выдаётся автоматически как бесплатный материал.
