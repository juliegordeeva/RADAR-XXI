# Корпоративный университет — изменения 21.10.2026

Реализовано по файлу Юлии `RADAR_KIDS_cursor_universitet.md` от 19.10 и переписке из задачи. Исходный файл прочитан из Downloads. Указание про бот заменено решением пользователя о прохождении на сайте; обучение и хранение отметок требуют отдельной реализации. Указания документа про коммиты не выполнялись. Сообщение «Заявка ушла» заменено подготовкой текста для самостоятельной отправки.

## Что готово

- Главная с новым первым экраном, крупным Радариком, семейной прогулкой, меморандумом и четырьмя шагами.
- Единая модель 12 навыков, четырёх компетенций и отдельной основы. Перепривязаны все продукты; страницы и существующие данные сохранены.
- «Наш подход»: лестница к взрослой оценке, 12 развёрнутых описаний с признаками прогресса, основа, уровни радара и таблица продуктов.
- Университет `/ru/universitet/` и `/en/universitet/`: отдельный первый экран с новой иллюстрацией семейной проектной мастерской, возрастной фильтр стажировок, планируемый формат, пример трёх недель, условный радар в разделе результатов, подбор докачки, FAQ и лист ожидания.
- Каталог с `?sector=`; старые `?skill=` не ломают страницу. В карточках до трёх тегов навыков, у родительских продуктов — отдельная подпись.
- Форма по QR: источник, код компании, программа, возраст и UTM. Неизвестные значения игнорируются. Нельзя выбрать неготовую программу или отправить форму без согласия.
- RU/EN, навигация, sitemap, метаданные и JSON-LD FAQ.

Ни одна стажировка ещё не запущена: нет готового курса и инструмента сбора наблюдений. Вводные программы принимают только интерес в лист ожидания, профильные и проектная показывают «Скоро». Даты и цены не подставлены. «9 вопросов» сохранён по прежнему адресу как черновик, из докачки исключён вместе с остальными неготовыми продуктами.

## Визуальное уточнение

По обратной связи пользователя два одинаковых первых экрана с диаграммой заменены разными композициями. Главная возвращает узнаваемых героев прежнего стиля: Радарика и семью на прогулке. Университет открывается широким заголовком и сгенерированной сценой проектной мастерской на мятном фоне, с жёлтым кругом и коралловым акцентом. Диаграмма сохранена в содержательном разделе «Радар навыков» и в первом экране страницы подхода рядом с новым Радариком. Текст «Современный контекст» сохранён ниже. У формы появился Радарик с блокнотом.

Используются WebP из `public/images/radar/`, включая две новые сгенерированные иллюстрации. В изображениях нет подписей интерфейса; диаграмма и подписи навыков — SVG/HTML. Промпты и пути сохранены в [описании генерации](redesign/GENERATED_UNIVERSITY_ART.md). На мобильном кнопка главной стоит перед иллюстрациями, описание остаётся ниже. Порядок меню: главная первой, университет вторым.

Проверены новые первые экраны RU/EN в Chrome, включая 2048, 1440, 1280, 390 и 360 px; скриншоты находятся локально в `/tmp/radar-hero-preview/` и `/tmp/radar-new-art-preview/` и в Git не добавлены.

## Разделение материалов по аудитории

- `/ru/produkty/` и `/en/produkty/` — только детские продукты, фильтры возраста и компетенции. На первом экране — дети за чтением и рисованием.
- Прежние ссылки `/ru/produkty/?age=parents` и `/en/produkty/?age=parents` открывают отдельное оформление для взрослого: календарь и ежедневник, родители с планером, без фильтров детских навыков. Случайный `sector` в такой ссылке не скрывает взрослые материалы.
- Заголовки и описания различаются в RU/EN; название «Материалы для вашей семьи» заменено на «Материалы для детей».
- Возврат из взрослого продукта ведёт в родительский каталог. Рекомендации на странице продукта остаются в той же аудитории. Данные продуктов и цены сохранены.
- Первоначальный HTML каталога содержит детский заголовок и иллюстрацию; родительский режим включается по существующему параметру после загрузки страницы. Адреса статического экспорта сохранены.
- `npm run test:catalog` проверяет разделение аудиторий и совместную работу детских фильтров.

## Просмотр

Нужен Node.js 22.20 или новее в ветке 22.

```sh
npm ci
npm run dev
```

Открыть `http://localhost:3000/ru/` и `http://localhost:3000/ru/universitet/`.

QR-пример: `http://localhost:3000/ru/universitet/?from=office-day&company=TEST&program=intro-7-9`.

```sh
npm run lint
npm run test:university
npm run build
```

Для проверки экспорта без префикса: `python3 -m http.server 4173 --directory out`, затем `http://localhost:4173/ru/universitet/`. `next start` не используется для статического экспорта.

Сборка с префиксом GitHub Pages:

```sh
GITHUB_PAGES=true NEXT_PUBLIC_SITE_URL=https://juliegordeeva.github.io/RADAR-XXI npm run build
```

Сайт из такой сборки должен обслуживаться по `/RADAR-XXI/`. Для собственного домена применяется обычная сборка без `GITHUB_PAGES=true`. Настройки публикации в этой задаче не менялись.
