# Доводка композиции v03 — 13 октября 2026

Изучены все 13 изображений из `design/pages/`, затем компоненты и CSS. Сделаны браузерные снимки до и после изменений. Главная дополнительно приведена к ширине 1024 px для сопоставления с эталоном при одинаковом масштабе.

## Изменения

- Общие ширина меню, отступ контента, масштаб заголовков и интервал секций вынесены в CSS-переменные. Убрано дополнительное центрирование контейнера внутри правой части страницы.
- На главной заголовок и CTA находятся слева, крупный Радарик справа, семья входит в первый блок. Добавлены мятная фоновая форма и коралловый диагональный акцент. Иллюстрация ограничена высотой первого блока, включая широкий экран.
- Исправлено перекрытие возрастного блока меню, обнаруженное на пользовательском скриншоте: меню главной теперь размещено внутри первого блока и получает его фактическую высоту средствами CSS. Приблизительный расчёт высоты через ширину окна удалён. Нижние полосы главной занимают всю ширину страницы.
- «Наши материалы» имеет асимметричную сетку: крупная левая область с отдельным положением текста и сцены, узкая правая область с вертикальной линией.
- Каталог: фильтры ближе к первому экрану, широкие родительские материалы, две колонки детских продуктов. Календарь показывает настоящий исходный материал; ежедневник — взрослую сцену и подписанную декоративную иллюстрацию разворота.
- У первых экранов каталога, подхода, команды, контактов, безопасности, календаря, ежедневника и корпоративных страниц свои размеры и пропорции. Office Day и походы используют крупную сцену снизу и справа.
- Полные названия продуктов сохранены. Описательная часть названия отделена меньшей строкой, чтобы длинные названия не разрывались посреди слова.
- Добавлены иллюстрации к трём направлениям подхода и четырём шагам Office Day. Уточнены размеры чередующихся корпоративных блоков, портретов команды и оглавления политики.
- Мобильные сетки и размеры настроены отдельно. Данные продуктов, B2B и команды, юридический текст, адреса, локали и действующие функции сохранены.

## Просмотр

В текущей сессии статическая сборка доступна на http://localhost:3006/ru/ и http://localhost:3006/en/.

Для разработки:

```sh
npm run dev
```

В среде этой сессии Node.js установлен временно; если `npm` отсутствует в PATH:

```sh
export PATH="/tmp/node-v22.20.0-darwin-x64/bin:$PATH"
npm run dev
```

Откройте `/ru/` на адресе, который напечатает Next.js. Для статического просмотра:

```sh
npm run build
python3 -m http.server 3006 --bind 127.0.0.1 --directory out
```

## Что ещё требуется для точного совпадения

В комплекте нет всех отдельных сцен и предметных превью, показанных в сгенерированных макетах. Нужны утверждённые лицевая и оборотная стороны карточек безопасности, превью остальных детских продуктов, настоящие обложка и развороты ежедневника, отдельные иллюстрации шагов Office Day и подхода. Они позволят довести предметную композицию до эталонов. Сейчас используются доступные сцены; рисунки ежедневника подписаны как декоративные, а не реальные страницы продукта.
