# RADAR KIDS · брендбук 2.0 · первый этап

Рабочая ветка: `redesign/brandbook-v2`. Публикация и отправка в удалённый репозиторий не выполнялись.

## Что готово

- Общая палитра, локальные Rubik Regular/Bold и Noto Sans Regular/Bold, кнопки, карточки, возрастные метки, шапка, мобильное меню и подвал.
- Главная на русском и английском: одна кнопка первого экрана, возрастная витрина, пример настоящего материала, шаги использования, подход, существующая команда, FAQ и завершение.
- Общий шаблон продукта: пример раньше длинных объяснений, аудитория, состав, использование, обсуждение, стоимость и прямое обращение. Образец — карточки безопасности.
- Старые адреса продуктов, данные `content/products.ts`, статический экспорт и конфигурация GitHub Pages сохранены.
- Общие формы готовят текст обращения. Пользователь может проверить, скопировать, вернуться к заполненной форме и самостоятельно отправить сообщение в Telegram. При отказе буфера текст остаётся доступен для ручного копирования. На главной и в шаблоне продукта — прямой чат без сбора почты.

Остальные страницы получили общие стили и исправление механики обращений. Их содержательный редизайн оставлен на следующий этап.

## Посмотреть

Нужен Node.js 22 и npm. На этой машине они отсутствовали в PATH; для проверок Node.js загружен во временную папку. В текущей сессии можно сначала выполнить:

```sh
export PATH="/tmp/node-v22.20.0-darwin-x64/bin:$PATH"
```

Для постоянной работы установите Node.js 22 обычным для вас способом. Дальше, из корня проекта:

```sh
npm ci
npm run dev
```

- Главная: http://localhost:3000/ru/
- Карточки безопасности: http://localhost:3000/ru/produkty/kartochki-bezopasnosti/
- Английские образцы: те же пути с `/en/`.
- Компоненты: http://localhost:3000/dev/ui/

Проверка и просмотр статического экспорта:

```sh
npm run build
python3 -m http.server 3000 --bind 127.0.0.1 --directory out
```

При `output: "export"` команда `next start` не используется. Для GitHub Pages:

```sh
GITHUB_PAGES=true npm run build
```

Эта команда только собирает файлы с префиксом `/RADAR-XXI`, ничего не публикует.

## Материалы и решения

Прочитаны новое ТЗ, `design/brandbook/README.txt`, токены, правила проекта; PDF извлечён и визуально просмотрен через PDFKit, просмотрены все пять PNG-эталонов. Непрочитанных файлов из запрошенного комплекта нет.

Из `references/scenes.png` выделены две самостоятельные сцены: верхняя правая для первого экрана и нижняя левая для подхода. Они сохранены в WebP; лица и руки не обрезаны. Полные модельные листы на сайте не используются. Готовые SVG подключены как отдельные декоративные элементы, пиктограммы имеют текстовые подписи. Лицензия и уведомления шрифтов сохранены в `public/fonts/` и исходном комплекте.

Карточка безопасности в примере — существующее изображение, а не новый дизайн учебного набора. Рядом в HTML приведена инструкция из `content/samples.ts` без методической переработки. Для английской страницы дан перевод инструкции и подпись о русской версии изображения. Новых иллюстрированных учебных карточек на этом этапе не создавали.

Главная показывает до трёх материалов одновременно. Временная подборка: безопасность, два адвента и три квеста; при выборе возраста витрина фильтруется. Для 13–16 лет показан переход в полный каталог с сохранённым возрастом. Выбор команды для окончательной витрины ещё нужен.

## Уточнить перед выпуском

1. Подтвердить готовность каждого продукта и формата: PDF, бот, печать; стоимость и реальный порядок получения. Сейчас карточки безопасности предлагают уточнить условия в Telegram.
2. Подтвердить 45 карточек, пять тематических блоков и возраст 4–8 лет. Значения фильтров 4–6 и 7–9 сохранены; на карточке и странице явно написано 4–8.
3. Предоставить актуальные лицевую/оборотную стороны в новой визуальной системе и пробный PDF. Старое превью сохранено как пример текущих материалов; новой карточкой с Радариком его не выдаём.
4. Согласовать главную витрину и новые тексты обеих локалей; предоставить английские товарные изображения.
5. Подтвердить календарь: 32 или 33 дня, название, текущую цену 800 ₽ из исходников и актуальное изображение.
6. Подтвердить фото, биографии, авторство и конкретные направления работы команды. Существующие роли сохранены, новые авторы не назначены.
7. Подтвердить Telegram, телефоны, домен, юридический текст и реквизиты.
