## Что изменилось

- Общий каркас: левая навигация с активным пунктом на широком экране; на телефоне и планшете — шапка и доступное меню. Сохранены фокус, Tab/Shift+Tab, Escape и возврат к кнопке открытия.
- Новая крупная типографика, асимметричные пары текста и иллюстрации, нумерованные открытые блоки. Общие стили и кнопки согласованы с выбранной версией №3.
- Локальные Rubik и Noto Sans подключены из `public/fonts/radar/`. Исходные TTF, OFL и уведомления сохранены.
- Иллюстрации подключаются из `public/images/radar/` в WebP. `BrandArt` использует размеры manifest и учитывает GitHub Pages basePath. SVG подключены из `graphics/`.
- Главная: самостоятельный крупный Радарик, отдельная семейная полоса, четыре возрастных маршрута, разные масштабы витрины и сюжетных областей, пример, подход, команда и FAQ.
- Каталог: маскот у заголовка, действующие фильтры; родительские материалы показаны отдельными крупными блоками с взрослыми сценами. Они учитывают фильтры и не дублируются в обычной сетке.
- Подход: собственное действие ребёнка, нумерованные объяснения, открытый список компетенций, отдельный взрослый блок и семейная сцена.
- Команда: реальные фотографии из пакета, чередование портрета и текста, исходные роли и биографии.
- Общий шаблон продукта: сюжетный первый экран, состав, инструкции, стоимость, обращение и связанные материалы. Календарь и ежедневник оформлены как взрослые продукты.
- Компании: три открытых программных области с отдельными сценами. Office Day, семейные походы и корпоративный ежедневник получили самостоятельные композиции.
- Контакты: Радарик с блокнотом, реальные телефоны, маршруты по темам и форма подготовки сообщения.
- Политика: оглавление с якорями и читаемая колонка. Юридический текст не изменён.

Все перечисленные страницы обновлены на RU/EN. Другие продукты используют общий шаблон. URL, статический экспорт, метаданные, sitemap/robots и конфигурация GitHub Pages сохранены.

`content/products.ts`, `content/b2b.ts`, `content/team.ts` побайтово совпадают с исходниками в Git. Цена календаря и корпоративные цены сохранены по существующим данным, новые не добавлялись. Текст `privacyPage` сохранён в обеих локалях.

## Реальные материалы и иллюстрации

Показаны настоящая обложка и Дни 1, 2, 9 календаря из `real-materials/`. Превью подписаны как русская версия; страницы можно открыть крупнее. Полный PDF находится только в `design/materials/`, публичной бесплатной загрузки нет.

Рисунки ежедневника из `illustrative-products/` подписаны как декоративные иллюстрации, не как реальные страницы или состав продукта. Подобные элементы макетов не добавляют характеристик товара.

Старые изображения из `existing-materials/` сохранены, но в новом дизайне не используются без подтверждения актуальности. Для безопасности новая сцена иллюстрирует ситуацию, а HTML-инструкция сохранена из текущих данных. Сцена не выдаётся за готовую карточку.

Формы показывают подготовленный текст, кнопку копирования и ссылку на Telegram. Данные остаются при возвращении к форме; отказ буфера позволяет скопировать вручную. Пользователь отправляет сообщение самостоятельно. Оплата и доставка на сайте не заявлены как автоматические.

## Что нужно уточнить или предоставить

- Актуальные лицевую и оборотную стороны карточек безопасности и реальные превью остальных детских материалов в новой системе.
- Оригинальные обложку и развороты родительского и корпоративного ежедневника.
- При необходимости — отдельные иллюстрации каждого шага Office Day и трёх направлений подхода; в комплекте есть общие сцены, а не все фрагменты макетов.
- Подтверждение текущих цен, доступности PDF/бота/печати, порядка получения; пробный файл для выдачи отдельно от полного платного календаря.
- Подтверждение названия и количества дней календаря, возраста безопасности 4–8 и состава 45 карточек, выбора главной витрины, авторства и контактных/юридических данных.

Эти вопросы отмечают границы исходных данных. Факты с макетов не переносились в продуктовые описания.

## Посмотреть

Текущая статическая версия: http://localhost:3004/ru/ (если локальный сервер ещё работает). Для EN замените `/ru/` на `/en/`.

Для разработки из корня проекта, если Node.js не установлен в PATH:

```sh
export PATH="/tmp/node-v22.20.0-darwin-x64/bin:$PATH"
npm run dev
```

Временная установка Node.js относится к текущей рабочей сессии. Для постоянной работы нужен Node.js 22. Next.js напечатает фактический адрес сервера, если порт 3000 занят.

Статический просмотр:

```sh
npm run build
python3 -m http.server 3004 --bind 127.0.0.1 --directory out
```

Сборка для GitHub Pages без публикации:

```sh
GITHUB_PAGES=true NEXT_PUBLIC_SITE_URL=https://juliegordeeva.github.io/RADAR-XXI npm run build
```
