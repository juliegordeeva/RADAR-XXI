## Особенности среды

Node.js/npm отсутствовали в PATH. Для проверки загружен Node.js 22.20.0 во временную папку; команды запускались с `/tmp/node-v22.20.0-darwin-x64/bin` в PATH. Песочница запрещала DNS-доступ к npm и локальные порты, поэтому установка и запуск локального сервера/Chrome выполнены через разрешённые команды вне песочницы. Блокировки устранены; сборка не осталась непроверенной.

PDF удалось прочитать и отрисовать через системный PDFKit. Веб-поиск и генерация новых иллюстраций для этой задачи не понадобились.
