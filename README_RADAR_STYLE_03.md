# RADAR KIDS. Макеты сайта в стиле версии №3

Распакуйте содержимое архива в корень существующего проекта RADAR-XXI, рядом с package.json.
Если распаковщик создал внешнюю папку с названием архива, перенесите её содержимое в корень проекта.

Внутри:
- design/pages/: выбранная главная №3 и 12 макетов остальных страниц;
- design/brandbook/: эталоны персонажей, SVG, токены, шрифты, лицензии и мастер-промпт;
- docs/RADAR_KIDS_Style_03_Implementation.md: актуальное дополнение к ТЗ и соответствие страниц;
- CODEX_START_STYLE_03.txt: готовое задание для Codex.

Код сайта в этот архив не входит. Оригинальные страницы и компоненты он не заменяет.
Файлы брендбука перенесены без изменения. PDF брендбука остаётся в ранее переданном комплекте; необходимые для реализации материалы включены здесь.

После распаковки откройте CODEX_START_STYLE_03.txt и отправьте его текст Codex в VS Code.

Макеты задают композицию, масштаб и характер оформления. Тексты, цены, состав, возраст, условия и юридический документ брать из актуального проекта и согласованных материалов. Изображения карточек и разворотов в макетах иллюстративные.
